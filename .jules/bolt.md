## 2024-05-24 - Optimizing Derived Data and Date Sorting in React Renders
**Learning:** Re-calculating multiple derived arrays (e.g. cross-filtering and mapping `pots`) on every render can cause measurable slowdowns in Next.js components that consume frequent context/hook updates. Additionally, using `new Date().getTime()` to sort ISO 8601 date strings inside an array sort callback is an unnecessary bottleneck; standard benchmark tests showed instantiating `Date` objects in a loop is approximately ~10x slower than using native string comparison with `localeCompare` for standard ISO formats.
**Action:** When working with derived data in components consuming global hooks like `useSavingsData`, always wrap O(N) or O(N log N) loops in `useMemo`. When sorting ISO date strings, use `a.localeCompare(b)` instead of instantiating `Date` objects.
