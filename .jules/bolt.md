## 2024-11-20 - O(N*M) React Renders & Date Parsing Bottlenecks
**Learning:** Benchmarks revealed two critical architectural bottlenecks in Dashboard components. First, running `array.filter()` inside a `.map` loop during component rendering causes an O(N*M) calculation that severely degrades performance as accounts scale. Second, inside `.sort()` functions, instantiating `new Date(str).getTime()` is ~45x slower than using string parsing or `str.localeCompare(str)` for ISO 8601 strings.
**Action:** Always wrap heavy data processing loops in `useMemo` hooks. When components need child lookups, replace O(N*M) nested loops with O(N) hash map grouping constructed inside the `useMemo` block. Strictly use `localeCompare` for sorting date strings instead of generating `Date` objects.
